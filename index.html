Экспертные настройки и ручные overrides
AUTO — самостоятельный быстрый расчёт: пользователь меняет только K, а готовый Reach из медиаплана не влияет на результат. В Detailed Web становятся доступны B, D и L. Если в файле есть итоговая Reach-кривая, она используется только для QA-сравнения.
Автоматический режим сам выбирает доступный путь. Детальный Web применяется к web-размещениям; остальные строки рассчитываются автоматически.
По умолчанию K = 2,44. Это коэффициент чувствительности AUTO: меньше K — выше прогнозный Reach, больше K — ниже. Ручное значение явно фиксируется как пользовательский override.
